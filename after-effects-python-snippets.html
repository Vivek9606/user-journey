How it works

STEP 1

You run a Python file

Each snippet is a small text file. The settings you want to change sit at the top, clearly labelled.

STEP 2

It writes an After Effects script

Python turns your settings into the instructions After Effects understands, and hands them over.

STEP 3

After Effects does the work

The change lands in your open project. One Ctrl+Z (Mac: Cmd+Z) undoes the whole thing.

Good to know: After Effects doesn't run Python by itself. Inside, it only reads JavaScript. These Python files work like a remote control: they write the JavaScript for you and send it to After Effects. If you'd rather skip Python, every snippet also has a plain .jsx version you can run from File › Scripts › Run Script File…

  1. Install Python

    Download it free from python.org/downloads. On Windows, tick “Add python.exe to PATH” on the first install screen.

  2. Save the helper file

    Make a folder, for example Desktop/KeyframeKit. Copy the helper below, paste it into Notepad (Mac: TextEdit, then Format › Make Plain Text) and save it in that folder as ae_bridge.py. In Notepad, set “Save as type” to All files.

If something goes wrong

    

      
“python is not recognized”
Python isn't on your PATH. Run the Python installer again, choose Modify, and tick “Add Python to environment variables”. On Mac, type python3 instead of python.

      
“Could not find After Effects”
After Effects is installed somewhere unusual. Open ae_bridge.py and paste the full path to AfterFX.exe (Mac: the app) between the quotes on the AE_PATH line.

      
“Open a composition first”
The snippet needs a comp open in the viewer. Double-click a comp in the Project panel, select the layers you want, and run it again.

      
It did something I didn't want
Press Ctrl+Z (Mac: Cmd+Z) once in After Effects. Each snippet is a single undo step named “Keyframe Kit”. Saving a new version is the one exception: the new file stays on disk.
